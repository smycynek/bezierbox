# A simple bezier app

In my spare time, I've tried to learn more about splines. So far, I have a simple bezier implementation.

## Installation

```bash
// Set up and debug

bun install
bun run dev


// Code styling

bun run lint
bun run format

// Deployment

bun run build
deploy.sh
```
